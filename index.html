Built for the public good

Tools for public work, built in the open and free for everyone.

County assessors do essential public work, often with limited staff and budgets. Some of the tools they need are too small or specialized to be worth building and maintaining commercially, but they are needed all the same. These are tools like that: built carefully once, shared freely, and improved together.

The approach

A few simple commitments shape every tool in this collection. They are not complicated, and that is the point — good public tools should be straightforward to trust.

Built once, shared with all

A small rural county gets exactly the same tool as the largest urban one. Build it carefully a single time, and every office benefits equally — no office is too small to be served well.

Open by default

The code, the methods, and the assumptions behind every tool are open to inspection. Anything that affects the public should be something the public is able to examine.

Free, and free to stay that way

No logins, no fees, no data collection, and nothing to lock into. These tools are free to use today, and built so they can stay free to use tomorrow.

These tools were built with substantial help from AI. That is stated plainly here, and again on each tool, because work done for the public should be honest about how it was made.

The tools

Two are available now, with more planned. Each one is self-contained, free, and runs entirely in the browser — nothing to install, no data leaving the page.

For homeowners

Property Tax Exemption Screening Tool

Washington's property tax exemption program for senior citizens and people with disabilities expanded substantially in tax year 2027 under Engrossed Substitute Senate Bill 6162. This screening tool walks a homeowner from county selection through eligibility, household composition, and an income calculation, then returns a clear, county-specific result with a printable summary.

  • Walks homeowners through 5 questions: county, age or disability, residence, household, income
  • Returns a clear A/B/C level result showing what they'd be exempt from
  • Compares 2026 thresholds to the new 2027 law for the county they select
  • Generates a printable summary with the documents to bring to the assessor's office
  • Links directly to the county assessor's office for the official determination

For assessor offices

Sales Ratio Analysis

A self-contained sales ratio analysis tool for assessor offices to use during the assessment cycle, before certified values are finalized. Upload a validated sales file and produce IAAO 2025-grounded ratio statistics, vertical equity diagnostics, and modifier recommendations. Not a substitute for the official vertical equity report.

  • Accepts CSV or Excel (.xlsx) sales files with automatic column mapping
  • Overall ratio diagnostics: median, COD, PRD, PRB with IAAO threshold flags
  • Time adjustment, vertical equity, and stratified analysis by neighborhood or use code
  • Modifier recommendations to support assessment cycle decisions
  • Runs entirely in the browser; no data leaves the analyst's machine

Open and shared

Built for Washington. Free for anyone.

Every tool here was made for Washington's county assessor offices, but nothing about the approach is specific to Washington. The code is open source. Any assessor's office, any state association, anyone doing public work is welcome to take these tools, adapt them, host them, and make them their own. If the model is useful, use it.
